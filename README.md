# Proyecto Final: Git + HTML/CSS

## Descripción

Este proyecto corresponde a una actividad colaborativa de desarrollo web
utilizando HTML5, CSS3, Git y GitHub.

El objetivo es aplicar buenas prácticas de control de versiones y
colaboración entre estudiantes.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub
